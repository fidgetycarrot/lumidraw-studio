# Lumi Studio 1.13.1 — Paige never replaces anyone

- A character or persona coming from Paige (through LumiCast) is always saved as a new entry. If the name is already taken, it's saved as "Vesper 2" (or 3, 4…). Its image anchor stays the real name, so it's still drawn as Vesper.
- Those entries get an orange **needs a new name** badge, and the top of the library list names them. The badge stays until you rename the entry, even if you edit and save it in the meantime.
