# Lumi Studio 1.47.0

Use a picture as an avatar in Lumiverse.

- **Avatar…** in the hover menu of any portrait in the Library, and **Use as avatar…** in the picture viewer for any picture.
- Pick a character card or a persona. This chat's card and persona come first, then the face's story cards and anyone with the same name. Search finds the rest.
- You see the round crop before saving. Tall pictures keep the top (the head), wide ones keep the middle. Lumiverse gets both the square and the full picture, like its own avatar editor.
- The avatar being replaced is kept, and **Put back the old one** restores it. If you change the same avatar again, the kept copy is still the one from before Lumi Studio first touched it.
- Card avatars show beside every narrator message in that card's chats.

Under the hood: the upload goes to the same address Lumiverse's own editors use. For cards, the official extension call is a fallback (it only takes the square).
